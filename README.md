# Fun - Interactive Web Experience

A modern, responsive, and beautifully designed website showcasing interactive features and smooth animations.

## Features

- **Responsive Design**: Perfectly optimized for all devices (mobile, tablet, desktop)
- **Modern UI/UX**: Clean and professional design with smooth animations
- **Interactive Elements**: Engaging hover effects and scroll animations
- **Accessibility**: WCAG compliant with keyboard navigation support
- **Performance Optimized**: Fast loading and smooth performance
- **Cross-browser Compatible**: Works seamlessly across all modern browsers

## Technologies Used

- HTML5
- CSS3 (with custom properties and animations)
- Vanilla JavaScript (ES6+)
- Google Fonts (Poppins)

## Sections

1. **Hero Section**: Eye-catching landing area with animated background
2. **Features**: Showcases 6 key features with interactive cards
3. **Gallery**: Interactive project showcase with hover effects
4. **Contact**: Functional contact form with validation
5. **Footer**: Social links and copyright information

## Getting Started

### View Online

Visit the live website at: [https://dillonpatterson.github.io/Fun/](https://dillonpatterson.github.io/Fun/)

### Local Development

1. Clone the repository:
   ```bash
   git clone https://github.com/DillonPatterson/Fun.git
   cd Fun
   ```

2. Open `index.html` in your browser:
   - Double-click the file, or
   - Use a local server like Live Server in VS Code
   - Or run: `python -m http.server 8000` (Python 3)

## Customization

### Colors
Edit the CSS custom properties in `styles.css`:
```css
:root {
    --primary-color: #667eea;
    --secondary-color: #764ba2;
    --accent-color: #f093fb;
    /* ... */
}
```

### Content
Edit the HTML in `index.html` to change text, titles, and content.

### Animations
Modify timing and effects in `styles.css` and `script.js`.
